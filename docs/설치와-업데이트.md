# 설치와 업데이트

## Windows 설치

- 대상: Windows 10/11 64비트
- 파일 이름: `DocuLensLocal-win-Setup.exe`
- 최신: https://github.com/boam79/DocuLensLocal/releases/latest
- 0.1.29 직접 주소: https://github.com/boam79/DocuLensLocal/releases/download/v0.1.29/DocuLensLocal-win-Setup.exe

GitHub Releases의 **Assets**가 잠시 돌아가 보일 수 있습니다. 끝나지 않으면 위 직접 주소를 브라우저에 붙여 넣으세요.

실행하면 설치 진행 화면이 나옵니다. 코드 서명이 없어 Windows가 경고를 띄울 수 있습니다. 추가 정보를 연 뒤 실행을 선택하세요.

설치가 끝나면 **인덱싱할 폴더를 선택하세요** 창이 나와야 합니다. 빈 화면이면 설치가 덜 된 것입니다.

Mac용 `.pkg` / 설치 파일은 만들지 않습니다.

## 앱에서 업데이트

새 버전이 GitHub Releases에 있으면:

1. 앱을 켤 때 팝업이 뜹니다. **어떤 버전이 생겼는지** 짧은 목록이 함께 보입니다. **확인**을 누르면 받고 다시 시작합니다.
2. 또는 **정보** 탭의 **업데이트**를 누릅니다. 새 버전이 있으면 같은 팝업이 뜹니다.

다시 켜진 뒤 **업데이트 내역**(버전과 짧은 한국어 설명)을 보여 줍니다. 설치 파일로 올린 경우에도, 이전에 쓰던 버전과 다르면 같은 내역 팝업이 뜹니다. 인덱싱 중에 업데이트해도, 다시 시작한 뒤 남은 파일부터 이어서 읽습니다.

개발용 `dotnet run`으로 띄운 창은 설치본이 아니라서, 이 버튼으로 설치 업데이트를 적용하지 않습니다. 「최신입니다」로 위장하지도 않습니다.

## 데이터가 남는 위치

검색 목록과 설정은 Velopack 설치 폴더(`current\`)가 아니라 아래입니다.

`%LOCALAPPDATA%\DocuLensLocal\userdata`

여기에는 `index.db`, `settings.json`, OCR 언어 파일이 있습니다. 원본 계약서 폴더는 그대로 있습니다.
