# 프로그램 구조

문서는 이 컴퓨터에만 두고, 원본은 읽기만 한다는 전제로 구성되어 있습니다.

## 프로젝트

솔루션 파일은 `DocuLensLocal.slnx`입니다.

| 프로젝트 | 역할 |
|---|---|
| `src/DocuLensLocal.App` | Avalonia 화면. Windows·macOS에서 `dotnet run`으로 실행. 인덱싱도 이 프로세스에서 호출합니다. |
| `src/DocuLensLocal.Core` | 발견·추출·OCR·SQLite 검색·업데이트 문구 |
| `src/DocuLensLocal.Worker` | 콘솔 뼈대만 있습니다. 실제 인덱싱은 App이 Core `IndexingService`를 직접 호출합니다. |
| `tests/DocuLensLocal.Core.Tests` | 동작 테스트 |

화면은 WPF가 아니라 Avalonia 11 + `net10.0`입니다. Mac에서도 같은 프로젝트를 빌드합니다.

## 화면이 하는 일

- 최초 실행: 폴더 선택 → 인덱싱
- 검색: 질의, 종류 필터, 결과 행(강조·열기·폴더에서 보기)
- 정보: 버전 타임라인, GitHub Releases 업데이트(Velopack)

## 코어가 하는 일

- **발견**: 폴더 재귀, `IndexableFiles`로 확장자 분류
- **추출**: PDF는 PdfPig(디지털) + 필요 시 OCR. Word는 ZIP XML / 구형 `.doc` OLE. 한글은 HwpLibSharp / HWPX ZIP. Excel은 sharedStrings·시트 / 구형 `.xls` SST. NPOI는 쓰지 않습니다.
- **OCR**: Tesseract 5 (`tesseract50.dll`), tessdata_fast `kor`·`eng`. 페이지마다 엔진을 새로 만들지 않습니다.
- **검색**: SQLite `index.db`. 토큰 AND 후 없으면 OR. 파일명 또는 `body_text`.
- **감시**: `FileSystemWatcher` 필터 `*`, 디바운스 후 `NewAndChanged` 패스
- **업데이트**: Velopack `GithubSource` (저장소 `boam79/DocuLensLocal`)

## 저장 위치

| 항목 | 위치 |
|---|---|
| 원본 문서 | 사용자가 고른 폴더 (수정하지 않음) |
| 검색 목록 | `userdata\index.db` |
| 설정 | `userdata\settings.json` (폴더 경로, 인덱싱 완료 여부, 업데이트 이어가기) |
| OCR 언어 | `userdata\tessdata` 또는 설치본 `tessdata` |

인덱스를 설치본 `current\`에 두면 업데이트 때 사라지므로 두지 않습니다.

## 검색 종류 필터

`SearchFormatFilter`는 플래그입니다. 없음(0)은 전체, PDF/Word/한글/Excel 비트를 켜고 끕니다. 결과 행 색은 같은 그룹을 씁니다.
