# 사용 안내

DocuLens Local은 이 컴퓨터 안의 PDF·Word·한글·Excel을 **파일 이름과 본문**으로 찾는 프로그램입니다. 계약서·인수인계 문서를 원래 폴더에 둔 채 읽고, 원문은 인터넷으로 보내지 않습니다.

## 처음 실행

1. Windows 설치 파일을 받아 실행합니다. → [설치와 업데이트](설치와-업데이트.md)
2. **인덱싱할 폴더를 선택하세요** 안내가 나옵니다.
3. **폴더 선택**으로 문서가 들어 있는 폴더를 고릅니다. 그 폴더 **아래쪽**에 있는 파일만 읽습니다.
4. **인덱싱**을 누릅니다. 폴더만 고르고 인덱싱을 안 누르면 검색 목록은 만들어지지 않습니다.
5. 끝나면 **문서 검색** 화면으로 바뀝니다.

다른 PC에서는 그 PC에 설치한 뒤, 그 PC에서 열리는 폴더를 다시 고르면 됩니다. 폴더 이름이 `계약서`가 아니어도 됩니다.

## 매일 쓰는 화면

위쪽에 **검색**과 **정보** 탭이 있습니다.

- **검색**: 단어를 넣고 문서를 찾습니다. → [검색](검색.md)
- **정보**: 지금 폴더·건수·본문/OCR, 짧은 팁, 최근 버전 이력, **업데이트**

아래쪽 **폴더**를 누르면 메뉴가 나옵니다. 지금 읽고 있는 폴더 경로는 검색 제목 바로 아래와 **정보** 탭에도 있고, 누르면 탐색기가 열립니다.

| 메뉴 | 하는 일 |
|---|---|
| 폴더 변경 | 다른 폴더를 고릅니다. 고른 뒤 인덱싱이 필요합니다. |
| 새 파일만 읽기 | 이미 읽은 파일은 두고, 새로 넣거나 바뀐 파일만 읽습니다. |
| 처음부터 다시 읽기 | 이 앱의 검색 목록만 지우고 폴더를 전부 다시 읽습니다. 원본 파일은 건드리지 않습니다. 한 번 더 확인합니다. |

앱이 켜져 있는 동안 폴더에 파일을 넣으면 잠시 후 **자동으로** 그 파일만 읽습니다. → [인덱싱](인덱싱.md)

## 하지 않는 일

- 원본 파일을 수정하거나 옮기지 않습니다. 읽기만 합니다.
- 문서를 클라우드나 AI 서버로 보내지 않습니다.
- Mac용 설치 파일은 없습니다. Mac에서는 개발할 때만 `dotnet run`으로 띄웁니다. → [개발](개발.md)
