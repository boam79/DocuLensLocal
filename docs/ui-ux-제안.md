# 프런트 디자인 · UI/UX 제안

기준 화면은 **0.1.27**입니다. 이미 된 것(종류 여러 개, 결과에서 열기·강조·색 칸, **1안 검색 화면 정리**)은 다시 제안하지 않습니다.

전제: 계약·인수인계를 찾는 **비기술 사용자**, 원문은 PC 밖 송신 없음, Mac 설치본 없음. presets·다크 모드·미리보기 창은 나중입니다.

## 1안 — 검색 화면을 도구처럼 (0.1.27에서 적용)

매일 쓰는 검색 탭만 손봤습니다. 기능은 그대로입니다.

- 종류 칸을 **작은 알약**으로 줄였습니다. 고르면 테두리가 생기고, 「여러 개 가능」이 한눈에 보입니다.
- **지금 폴더**를 제목 바로 아래로 올렸습니다. 경로를 누르면 탐색기가 열립니다.
- 아래 세 버튼은 **폴더** 메뉴 한 줄입니다. 「처음부터 다시 읽기」는 한 번 더 확인한 뒤에만 실행합니다.
- 검색 후 목록 위에 **12건**처럼 건수를 보여 줍니다.
- 오른쪽 위 알약은 `276개 · OCR 있음`처럼 짧게 둡니다.
- 빈 화면 안내는 **한 줄 + 예시 칩**만 남깁니다. 종류 안내는 칸을 고른 뒤에만 보입니다.

## 아직 안 한 것

## 2안 — 처음 실행과 읽는 중

- 버튼을 **이 폴더 읽기** 하나로 합니다. 폴더를 고르면 바로 읽기 시작하거나, 고른 뒤 큰 버튼 하나만 남깁니다.
- 읽는 중에는 건수 글자 대신 **진행 막대**와 「지금: 파일 이름」만 보여 줍니다.
- 끝나면 검색창에 커서가 가 있게 합니다.

## 3안 — 결과 줄을 더 짧게

- **열기**만 분명한 버튼으로 두고, 폴더에서 보기는 작은 아이콘으로 둡니다.
- 줄을 한 번 눌러도 열리게 할지, 두 번만 열지는 지금처럼 두 번 + 버튼으로 유지해도 됩니다. 한 번 클릭 선택은 실수로 파일이 많이 열릴 수 있어 비추천입니다.
- 창 기본 너비를 조금 넓혀 근거 문장이 덜 잘리게 합니다.

## 4안 — 정보 탭 (0.1.27 화면 기준, 미구현)

지금 **정보** 탭은 제품 이름, 버전 알약, 긴 버전 히스토리, 맨 아래 **업데이트**입니다. 매일 「이 폴더를 보고 있나」를 확인하는 데는 도움이 적습니다. 검색 탭에서 자세한 건수·OCR을 짧게 줄였으니, 그 숫자는 여기로 오는 것이 맞습니다.

하지 않는 것: 설정 화면, 다크 모드, GitHub 로고, 기술 경로(`%LOCALAPPDATA%`) 노출.

### 지금 거슬리는 점

1. 창 제목과 같은 **DocuLens Local**이 한 번 더 큽니다. 아래 이력과 구분이 약합니다.
2. **버전 히스토리**가 화면의 대부분입니다. 0.1.0까지 스크롤됩니다. 매일 볼 내용이 아닙니다.
3. 지금 읽는 **폴더·건수·OCR**이 없습니다. 검색 탭 알약은 짧게만 보여 줍니다.
4. 아래 회색 글 `GitHub Releases에서…`는 설치 파일 받는 사람에게는 어려운 말입니다.

### 정보 1안 — 이 앱 상태 (가장 추천)

위는 **지금 상태**, 아래는 **짧은 이력**, 맨 아래 **업데이트**는 그대로 둡니다.

- 큰 제품 이름 대신 `이 컴퓨터에서만 찾습니다` 한 줄.
- 회색 상자 하나: **지금 폴더**(누르면 탐색기) · `278개` · `본문 있음` · `OCR 있음`. 숫자는 `본문 278건 · OCR 707쪽`처럼 풀어도 됩니다.
- 팁 세 줄만: 종류는 여러 개 가능 / 결과에서 열기 / 폴더가 다르면 안 나옴.
- 버전 히스토리는 **최근 5개**만. 더 보면 `이전 버전`을 눌러 펼칩니다. 지금 버전은 점이 채워집니다.
- 업데이트 버튼은 그대로. 아래 글은 `새 버전이 있으면 여기서 받습니다.`

성공하면: 정보 탭이 「설명서」가 아니라 「잘 읽고 있는지 확인하는 곳」이 됩니다.

### 정보 2안 — 업데이트 중심

이력을 거의 숨깁니다.

- 위: 버전 알약 + `최신입니다` 또는 `새 버전 있음`.
- 가운데: 폴더·건수만 한 줄.
- 아래: 큰 **업데이트**. 히스토리는 `무엇이 바뀌었나`를 눌러야 보입니다.

업데이트만 자주 누르는 사람에게는 단순합니다. 폴더가 잘못된 걸 알아채기는 1안보다 약합니다.

### 정보 3안 — 손만 조금

레이아웃은 그대로 두고 글만 고칩니다.

- 아래 문구를 `새 버전이 있으면 여기서 받습니다.`로.
- 이력은 최근 5개만.
- 폴더·건수·팁은 넣지 않습니다.

공기는 조금 줄어들지만, 정보 탭이 왜 있는지 설명은 안 됩니다.

## 추천 순서

**검색 1안은 0.1.27에 넣었습니다.** 정보 탭을 손본다면 **정보 1안만** 하는 것을 권합니다. 처음 실행(검색 2안)·결과 줄 아이콘(검색 3안)은 나중입니다.
