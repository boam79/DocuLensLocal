# 프런트 디자인 · UI/UX 제안

기준 화면은 **0.1.27**입니다. 이미 된 것(종류 여러 개, 결과에서 열기·강조·색 칸, **1안 검색 화면 정리**)은 다시 제안하지 않습니다.

전제: 계약·인수인계를 찾는 **비기술 사용자**, 원문은 PC 밖 송신 없음, Mac 설치본 없음. presets·다크 모드·미리보기 창은 나중입니다.

## 1안 — 검색 화면을 도구처럼 (0.1.27에서 적용)

매일 쓰는 검색 탭만 손봤습니다. 기능은 그대로입니다.

- 종류 칸을 **작은 알약**으로 줄였습니다. 고르면 테두리가 생기고, 「여러 개 가능」이 한눈에 보입니다.
- **지금 폴더**를 제목 바로 아래로 올렸습니다. 경로를 누르면 탐색기가 열립니다.
- 아래 세 버튼은 **폴더** 메뉴 한 줄입니다. 「처음부터 다시 읽기」는 한 번 더 확인한 뒤에만 실행합니다.
- 검색 후 목록 위에 **12건**처럼 건수를 보여 줍니다.
- 오른쪽 위 알약은 `276개 · OCR 있음`처럼 짧게 둡니다.
- 빈 화면 안내는 **한 줄 + 예시 칩**만 남깁니다. 종류 안내는 칸을 고른 뒤에만 보입니다.

## 아직 안 한 것

## 2안 — 처음 실행과 읽는 중

- 버튼을 **이 폴더 읽기** 하나로 합니다. 폴더를 고르면 바로 읽기 시작하거나, 고른 뒤 큰 버튼 하나만 남깁니다.
- 읽는 중에는 건수 글자 대신 **진행 막대**와 「지금: 파일 이름」만 보여 줍니다.
- 끝나면 검색창에 커서가 가 있게 합니다.

## 3안 — 결과 줄을 더 짧게

- **열기**만 분명한 버튼으로 두고, 폴더에서 보기는 작은 아이콘으로 둡니다.
- 줄을 한 번 눌러도 열리게 할지, 두 번만 열지는 지금처럼 두 번 + 버튼으로 유지해도 됩니다. 한 번 클릭 선택은 실수로 파일이 많이 열릴 수 있어 비추천입니다.
- 창 기본 너비를 조금 넓혀 근거 문장이 덜 잘리게 합니다.

## 4안 — 정보 탭을 「이 앱 상태」로

버전 이력은 아래로 두고, 위에 다음을 둡니다.

- 지금 폴더 경로
- 건수 · 본문 · OCR 쪽
- 짧은 사용 팁 세 줄 (종류 여러 개, 열기, 폴더가 다르면 안 나옴)

다크 모드, 트레이, 미리보기 분할창은 이 네 안보다 효과가 작습니다.

## 추천 순서

**1안은 0.1.27에 넣었습니다.** 다음으로 손볼 것은 2안(처음 실행)입니다.
