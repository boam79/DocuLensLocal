# 프런트 디자인 · UI/UX 제안

기준 화면은 **0.1.26**입니다. 이미 된 것(종류 여러 개, 결과에서 열기·강조·색 칸)은 다시 제안하지 않습니다.

전제: 계약·인수인계를 찾는 **비기술 사용자**, 원문은 PC 밖 송신 없음, Mac 설치본 없음.  presets·다크 모드·미리보기 창은 나중입니다.

## 지금 화면에서 거슬리는 점

1. 종류 칸이 **72×72**로 커서, 검색 결과가 뜨면 목록이 줄어듭니다. 로고처럼 보여서 「여러 개 필터」라는 느낌이 약합니다.
2. 안내 문구가 겹칩니다. 종류 아래 한 줄, 그 아래 「PDF · Word · …」, 「파일명이나 본문…」, 「검색하면 근거…」가 이어집니다.
3. 아래쪽 **폴더 변경 / 새 파일 인덱싱 / 처음부터 다시 인덱싱**이 같은 모양입니다. 지우는 동작과 폴더 바꾸기가 구분이 안 됩니다.
4. **지금 읽는 폴더**가 맨 아래 회색입니다. 파일이 안 나올 때 가장 먼저 봐야 할 정보가 가장 안 보입니다.
5. 오른쪽 위 알약 `인덱싱 완료 · 278건 · 본문 278건 · OCR 707쪽`이 한 덩어리라 읽는 데 힘이 듭니다.
6. 처음 실행은 **폴더 선택**과 **인덱싱** 두 단계입니다. 폴더만 고르고 멈추기 쉽습니다.
7. 결과 줄의 **폴더에서 보기**가 길어 목록이 답답합니다. 읽는 중에는 글자만 바뀌고 막대가 없습니다.
8. **정보** 탭은 버전 이력뿐입니다. 매일 「이 폴더를 보고 있다」는 확인에는 도움이 적습니다.

## 1안 — 검색 화면을 도구처럼 (가장 추천)

매일 쓰는 검색 탭만 손봅니다. 기능은 그대로입니다.

- 종류 칸을 **작은 알약**으로 줄입니다. 고르면 채워지고, 「여러 개 가능」이 한눈에 보입니다. 결과 목록 높이가 늘어납니다.
- **지금 폴더**를 제목 옆이나 검색창 바로 아래로 올립니다. 경로를 누르면 탐색기가 열리게 해도 됩니다.
- 아래 세 버튼은 **폴더** 한 줄로 줄입니다. 「처음부터 다시」는 메뉴나 한 번 더 확인 뒤에만 실행합니다.
- 검색 후 목록 위에 **12건**처럼 건수를 보여 줍니다.
- 오른쪽 위 알약은 `278개 · OCR 있음`처럼 짧게, 자세한 숫자는 정보 탭으로 보냅니다.
- 빈 화면 안내를 **한 줄 + 예시 칩**만 남깁니다.

성공하면: 같은 창에서 목록이 더 많이 보이고, 잘못된 폴더를 바로 알아챕니다.

## 2안 — 처음 실행과 읽는 중

- 버튼을 **이 폴더 읽기** 하나로 합니다. 폴더를 고르면 바로 읽기 시작하거나, 고른 뒤 큰 버튼 하나만 남깁니다.
- 읽는 중에는 건수 글자 대신 **진행 막대**와 「지금: 파일 이름」만 보여 줍니다.
- 끝나면 검색창에 커서가 가 있게 합니다.

## 3안 — 결과 줄을 더 짧게

- **열기**만 분명한 버튼으로 두고, 폴더에서 보기는 작은 아이콘으로 둡니다.
- 줄을 한 번 눌러도 열리게 할지, 두 번만 열지는 지금처럼 두 번 + 버튼으로 유지해도 됩니다. 한 번 클릭 선택은 실수로 파일이 많이 열릴 수 있어 비추천입니다.
- 창 기본 너비를 조금 넓혀 근거 문장이 덜 잘리게 합니다.

## 4안 — 정보 탭을 「이 앱 상태」로

버전 이력은 아래로 두고, 위에 다음을 둡니다.

- 지금 폴더 경로
- 건수 · 본문 · OCR 쪽
- 짧은 사용 팁 세 줄 (종류 여러 개, 열기, 폴더가 다르면 안 나옴)

다크 모드, 트레이, 미리보기 분할창은 이 네 안보다 효과가 작습니다.

## 추천 순서

**1안만** 하는 것을 권합니다. 눈에 띄는 변화는 「폴더가 보인다 + 종류가 필터처럼 작다 + 아래 버튼이 덜 무섭다」입니다.
