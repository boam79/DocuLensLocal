# 고도화

2026-08-22 제안입니다. 제품 전제(원문 비송신, 원본 읽기만, 폴더 하나, 비기술 사용자, Mac 설치 없음)는 유지합니다.

클라우드·AI로 문서를 보내는 검색·요약, 복잡한 설정 화면, Mac 설치본, 큰 미리보기 OCR 뷰어는 하지 않습니다.

## 한 것

### 검색 결과 (0.1.25) — 예전 P0

- 파일 이름·근거 문장에서 검색어 굵게
- **열기**, **폴더에서 보기**
- 종류 칸 색을 PDF/WORD/HWP/EXCEL 버튼과 맞춤
- 전체 경로 대신 상위 폴더 이름과 날짜

### 종류 여러 개 (0.1.26) — 예전 P2 일부

- PDF·WORD·HWP·EXCEL을 동시에 고를 수 있음
- 다시 누르면 그 종류만 빠짐
- 선택이 없으면 전체

### 검색 화면 정리 (0.1.27) — 1안

- 종류 칸을 작은 알약으로
- 지금 폴더를 제목 아래로, 누르면 탐색기
- 아래 세 버튼을 **폴더** 메뉴로. 「처음부터 다시 읽기」는 확인 뒤
- 검색 후 **12건** 표시
- 오른쪽 위 알약을 `276개 · OCR 있음`처럼 짧게
- 빈 화면은 한 줄 + 예시 칩

## 아직 안 한 것

### 처음 실행과 읽는 중 (2안)

- 최초 실행을 「이 폴더 읽기」 한 버튼으로
- 많이 읽을 때 진행 막대

### 찾기 조건의 나머지 (P2)

- 올해 / 최근 1년 같은 날짜
- 최근 검색어 (지금은 예시 칩이 버스 광고·부대·계약으로 고정)
- Enter로 첫 결과 열기

### 나중 (P3)

- 여러 폴더
- 근거에 페이지 번호
- 트레이 아이콘
- 다크 모드
- 결과 줄에서 폴더 보기를 아이콘으로 (3안)
- 정보 탭에 지금 폴더·건수·짧은 팁 (정보 1안)

## 프런트 UI/UX (0.1.27)

자세한 글: [ui-ux-제안.md](ui-ux-제안.md)

1. 검색 화면: 종류를 작은 알약으로, 폴더 경로를 위로, 아래 세 버튼을 줄임, 결과 건수 — **0.1.27에서 적용**
2. 처음 실행: 「이 폴더 읽기」 한 버튼, 진행 막대
3. 결과 줄: 열기만 큰 버튼, 폴더 보기는 아이콘, 창을 조금 넓힘
4. 정보 탭: 지금 폴더·건수·짧은 팁을 이력보다 위에. 이력은 최근 몇 개만. 업데이트 문구를 쉽게.

검색 1번은 넣었습니다. 정보 탭을 손본다면 4번의 **정보 1안만** 권합니다.
