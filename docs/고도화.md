## 한 것

### 검색 결과 (0.1.25) — 예전 P0

- 파일 이름·근거 문장에서 검색어 굵게
- **열기**, **폴더에서 보기**
- 종류 칸 색을 PDF/WORD/HWP/EXCEL 버튼과 맞춤
- 전체 경로 대신 상위 폴더 이름과 날짜

### 종류 여러 개 (0.1.26) — 예전 P2 일부

- PDF·WORD·HWP·EXCEL을 동시에 고를 수 있음
- 다시 누르면 그 종류만 빠짐
- 선택이 없으면 전체

## 아직 안 한 것

### 화면을 더 단순한 검색 도구처럼 (P1)

- 아래 세 버튼(폴더 변경 / 새 파일 / 처음부터 다시)이 비슷해 보임. 「폴더」 한 줄로 줄이고, 다시 인덱싱은 한 번 더 확인
- 지금 읽는 폴더 경로를 맨 아래 회색이 아니라 제목 근처로
- 최초 실행을 「이 폴더 읽기」 한 버튼으로
- 많이 읽을 때 진행 막대

### 찾기 조건의 나머지 (P2)

- 올해 / 최근 1년 같은 날짜
- 최근 검색어 (지금은 예시 칩이 버스 광고·부대·계약으로 고정)
- 결과 건수 표시
- Enter로 첫 결과 열기

### 나중 (P3)

- 여러 폴더
- 근거에 페이지 번호
- 트레이 아이콘
- 다크 모드
