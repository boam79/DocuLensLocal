## 한 것

### 검색 결과 (0.1.25) — 예전 P0

- 파일 이름·근거 문장에서 검색어 굵게
- **열기**, **폴더에서 보기**
- 종류 칸 색을 PDF/WORD/HWP/EXCEL 버튼과 맞춤
- 전체 경로 대신 상위 폴더 이름과 날짜

### 종류 여러 개 (0.1.26) — 예전 P2 일부

- PDF·WORD·HWP·EXCEL을 동시에 고를 수 있음
- 다시 누르면 그 종류만 빠짐
- 선택이 없으면 전체

### 검색 화면 정리 (0.1.27) — 1안

- 종류 칸을 작은 알약으로
- 지금 폴더를 제목 아래로, 누르면 탐색기
- 아래 세 버튼을 **폴더** 메뉴로. 「처음부터 다시 읽기」는 확인 뒤
- 검색 후 **12건** 표시
- 오른쪽 위 알약을 `276개 · OCR 있음`처럼 짧게
- 빈 화면은 한 줄 + 예시 칩

### 정보 탭 상태 (0.1.28) — 정보 1안

- `이 컴퓨터에서만 찾습니다`
- 지금 폴더·건수·본문·OCR, 팁 세 줄
- 버전 이력은 최근 5개 + **이전 버전**
- 업데이트 문구를 쉽게

### 업데이트 내역 팝업 (0.1.29)

- 새 버전이 있으면 팝업에 버전과 짧은 내역
- 설치 파일로 올린 뒤에도 내역 팝업

### PowerPoint (0.1.30) — 고도화 5안

- `.pptx` `.pptm` `.ppt` 본문 검색
- 스캔을 붙인 슬라이드는 Word와 같은 OCR
- 종류 칸에 **PPT**
