# 보안 제안

기준은 **0.1.28**입니다. 화면은 아직 안 바꿨습니다. 구현은 고른 뒤입니다.

전제: 계약·인수인계를 이 PC에서만 찾음, 원문은 인터넷으로 안 보냄, 원본은 읽기만, 비기술 사용자, Mac 설치 없음.

백신·방화벽을 대신하지 않습니다. 클라우드로 문서를 보내는 검색도 하지 않습니다.

## 지금 지켜지는 것

- 원본 PDF·Word·한글·Excel은 **읽기만** 합니다. 앱이 파일을 고치거나 옮기지 않습니다.
- 문서 원문을 클라우드나 AI 서버로 **보내지 않습니다.** 검색은 이 컴퓨터 안의 목록만 봅니다.
- 새 버전은 GitHub 주소에서 HTTPS로 받습니다. 앱 안에 다른 회사 서버 주소는 없습니다.
- 검색어는 목록 조회에만 씁니다. 문장을 그대로 SQL에 붙이지 않습니다.
- 엑셀 매크로(.xlsm)를 이 앱이 **실행하지 않습니다.** 글자만 읽습니다. **열기**를 누르면 엑셀·워드가 열리므로, 그때는 그 프로그램 규칙을 따릅니다.

## 알아 두면 좋은 점

1. **검색 목록**(`index.db`)에는 파일 이름과 **본문 글자**가 들어 있습니다. 그래서 검색이 됩니다. 이 Windows 계정으로 로그인하면, 다른 프로그램도 그 폴더를 읽을 수 있습니다. 원본 폴더를 열어 보는 것과 비슷한 수준입니다.
2. 설치 파일에 **코드 서명**이 없습니다. Windows가 「알 수 없는 게시자」경고를 띄울 수 있습니다. 지금 안내서에 이미 적혀 있습니다.
3. **열기**는 이 앱이 파일을 그리는 것이 아니라, Windows가 정해 둔 프로그램(엑셀, 워드, 한글, PDF 뷰어)을 켭니다.

하지 않는 것: 앱 비밀번호, 여러 사람용 로그인, 클라우드 백업, 백신 엔진.

## 보안 1안 — 화면에 약속을 분명히 (가장 추천)

정보 탭 상태 상자에 짧은 문장만 더합니다. 기능은 그대로입니다.

- `원문은 인터넷으로 보내지 않습니다. 검색용 글자는 이 컴퓨터에만 있습니다.`
- 매크로가 있을 수 있는 파일(`.xlsm`, 구형 `.doc`)을 **열기**로 열 때, 한 번만 `엑셀·워드가 엽니다. 매크로가 있으면 그 프로그램 경고를 따르세요.`

성공하면: 지금 지키는 약속이 정보 탭에서 보입니다. 설치 파일 서명·목록 암호화는 아직 없습니다.

## 보안 2안 — 설치 파일을 Windows가 덜 의심하게

Windows 코드 서명 인증서를 사서 Setup.exe에 서명합니다.

- 설치·업데이트 때 「알 수 없는 게시자」가 줄어듭니다.
- 인증서는 **매년 비용**이 들고, 회사 명의로 신청해야 합니다. 앱 코드만으로는 끝낼 수 없습니다.

가짜 설치 파일을 받아 실행하는 것을 완전히 막지는 못합니다. 공식 주소에서만 받는 습관이 더 중요합니다.

## 보안 3안 — 검색 목록을 USB로 복사해도 글자가 안 보이게

검색 목록 파일을 이 Windows 계정만 열 수 있게 잠급니다. USB로 `index.db`만 가져가면 글자가 안 보입니다.

- 이 PC에 로그인된 악성 프로그램까지는 막지 않습니다.
- 노트북을 켜 둔 채 자리를 비우면, 화면을 잠그는 것이 먼저입니다.
- 작업량이 보안 1안보다 큽니다.

## 추천 순서

**보안 1안만** 하는 것을 권합니다. 눈에 띄는 변화는 「정보 탭에서 원문을 안 보낸다고 확인」입니다.

서명(2안)은 인증서를 살 준비가 되면, 목록 잠금(3안)은 그다음입니다.
