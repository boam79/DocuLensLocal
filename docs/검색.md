# 검색

검색은 **파일 이름**과 **본문**(스캔이면 OCR 글자)을 함께 봅니다. 빈 칸에서 검색 버튼을 눌러도 전체 목록이 나오지 않습니다. 단어를 넣어야 합니다.

## 검색어

검색창에 단어를 넣고 **검색**을 누르거나 Enter를 누릅니다.

- `버스 광고`처럼 띄어 쓰면 각 단어를 찾습니다.
- `버스 광고 찾아줘`처럼 말하듯 넣어도 `찾아줘`는 빼고 버스·광고로 찾습니다.
- 붙여 쓴 `버스광고`도 버스·광고로 나눕니다.
- 예: 파일명이 `내부문서.docx`여도 본문에 「버스 광고 계약」이 있으면 찾을 수 있습니다.

**초기화**는 검색어만 지웁니다. 눌러 둔 종류(PDF 등)는 그대로입니다.

## 종류 버튼 (PDF · WORD · HWP · EXCEL)

검색창 아래 네 칸은 버튼입니다. **여러 개를 함께** 고를 수 있습니다. (0.1.26)

| 칸 | 포함 확장자 |
|---|---|
| PDF | `.pdf` |
| WORD | `.docx`, `.doc` |
| HWP | `.hwp`, `.hwpx` |
| EXCEL | `.xlsx`, `.xlsm`, `.xls` |

- 칸을 누르면 그 종류가 검색에 들어갑니다. 테두리가 생깁니다.
- 다른 칸을 또 누르면 **같이** 찾습니다. 예: PDF + EXCEL.
- **같은 칸을 다시 누르면** 그 종류만 빠집니다.
- **하나도 안 고르면** 지원하는 모든 종류를 찾습니다.
- 이미 검색한 뒤에도 칸을 바꾸면 같은 단어로 다시 찾습니다.

읽지 않는 것: `.txt`, 이미지, `~$`로 시작하는 Word/Excel 잠금 파일, `.xlsb`.

## 검색 결과 (0.1.25)

각 줄에는 다음이 보입니다.

- 왼쪽 색 칸: PDF / DOCX / HWP / XLSX 등. 색은 위 종류 버튼과 같습니다.
- 파일 이름: 검색어가 있으면 **굵게** 표시됩니다.
- 근거 문장: 본문에서 그 단어가 있는 근처. 검색어는 굵게 표시됩니다.
- 오른쪽 작은 글: `본문`, `파일명`, `파일명·본문`, 스캔이면 `OCR`.
- 아래 회색 줄: **상위 폴더 이름 · 날짜** (전체 경로는 넣지 않습니다.)
- **열기**: 그 파일을 기본 프로그램으로 엽니다. 줄을 두 번 눌러도 같습니다.
- **폴더에서 보기**: 탐색기에서 그 파일을 가리킵니다.
