# 검색

검색은 **파일 이름**과 **본문**(스캔이면 OCR 글자)을 함께 봅니다. 빈 칸에서 검색 버튼을 눌러도 전체 목록이 나오지 않습니다. 단어를 넣어야 합니다.

## 검색어

검색창에 단어를 넣고 **검색**을 누르거나 Enter를 누릅니다.

- `버스 광고`처럼 띄어 쓰면 각 단어를 찾습니다.
- `버스 광고 찾아줘`처럼 말하듯 넣어도 `찾아줘`는 빼고 버스·광고로 찾습니다.
- 붙여 쓴 `버스광고`도 버스·광고로 나눕니다.
- 예: 파일명이 `내부문서.docx`여도 본문에 「버스 광고 계약」이 있으면 찾을 수 있습니다.

**초기화**는 검색어와 **눌러 둔 종류**를 함께 지웁니다. 검색 옆 버튼을 누르면 PDF·WORD·HWP·EXCEL·PPT가 모두 꺼집니다.

## 종류 버튼 (PDF · WORD · HWP · EXCEL · PPT)

검색창 아래 다섯 칸은 작은 알약 버튼입니다. **여러 개를 함께** 고를 수 있습니다. (0.1.26, 모양은 0.1.27에서 알약, PPT는 0.1.30)

| 칸 | 포함 확장자 |
|---|---|
| PDF | `.pdf` |
| WORD | `.docx`, `.doc` |
| HWP | `.hwp`, `.hwpx` |
| EXCEL | `.xlsx`, `.xlsm`, `.xls` |
| PPT | `.pptx`, `.pptm`, `.ppt` |

- 칸을 누르면 그 종류가 검색에 들어갑니다. 테두리가 생깁니다.
- 다른 칸을 또 누르면 **같이** 찾습니다. 예: PDF + EXCEL.
- **같은 칸을 다시 누르면** 그 종류만 빠집니다.
- **초기화**를 누르면 고른 종류가 한 번에 모두 꺼집니다.
- **하나도 안 고르면** 지원하는 모든 종류를 찾습니다.
- 이미 검색한 뒤에도 칸을 바꾸면 같은 단어로 다시 찾습니다.

읽지 않는 것: `.txt`, 이미지, `~$`로 시작하는 Word/Excel/PowerPoint 잠금 파일, `.xlsb`.

## 검색 결과 (0.1.32)

검색하면 화면이 **왼쪽 파일 목록**과 **오른쪽 근거**로 나뉩니다. 왼쪽에서 이름을 한눈에 보고, 고른 파일의 본문 근거는 오른쪽입니다.

- 왼쪽: 종류 색 칸, 파일 이름, 상위 폴더·날짜, **열기**
- 오른쪽: 고른 파일 이름, `본문`/`파일명`/`OCR` 표시, 근거 문장(검색어 굵게), **열기**, **폴더에서 보기**
- 왼쪽 줄을 누르면 오른쪽이 바뀝니다. 줄을 두 번 눌러도 파일이 열립니다.

파일이 없거나 옮겨졌으면 안내가 뜹니다. **제목 아래 폴더 경로**가 실제 파일이 있는 위치와 같은지 먼저 보세요. 여러 폴더면 `경로 외 N개`입니다. 경로를 누르면 탐색기가 열립니다. 아래 **폴더** 메뉴에서 폴더를 더하거나 뺄 수 있습니다. → [자주 묻는 질문](자주-묻는-질문.md)

검색하면 종류 버튼 오른쪽에 **12건**처럼 건수가 보입니다.
