# 자주 묻는 질문

## 파일이 탐색기에는 있는데 검색에 안 나옵니다

1. 검색 화면 **제목 아래 폴더 경로**를 봅니다. 경로를 누르면 탐색기가 열립니다. 파일이 그 폴더(또는 그 아래)에 있어야 합니다. 상위 폴더에 있으면 안 읽힙니다. 아래 **폴더** → **폴더 변경**으로 파일이 있는 폴더를 고르세요.
2. 확장자가 PDF·Word·한글·Excel인지 봅니다. `.txt`·이미지는 건너뜁니다.
3. 종류 버튼(PDF 등)을 눌러 둔 상태면, 그 종류만 나옵니다. 칸을 다시 눌러 선택을 끄세요.
4. 검색어가 파일 이름에도 본문에도 없으면 결과가 없습니다. 빈 검색은 전체 목록이 아닙니다.
5. Word/Excel이 연 `~$` 임시 파일은 목록에 넣지 않습니다.

## 엑셀·한글이 「인덱싱이 안 된다」고 느껴집니다

먼저 제목 아래 경로와 탐색기 위치를 비교하세요. 예전에도 파일이 `인수인계`에 있고 앱은 `인수인계\계약서_스캔`만 보고 있던 경우가 있었습니다.

본문이 한 번 비어 저장된 엑셀·한글은, 최신 버전에서 앱을 다시 켜거나 **폴더** → **새 파일만 읽기**를 누르면 다시 읽습니다. 그래도 스캔만 있는 파일이면 **처음부터 다시 읽기**가 필요할 수 있습니다.

## 검색어가 본문에 있는데 안 나옵니다

디지털 글자가 거의 없는 스캔이면 OCR이 필요합니다. 설치본에는 엔진이 들어 있습니다. OCR이 끝난 뒤 다시 검색하세요. 오른쪽 위 알약의 「OCR 있음」이나 읽는 중 글자가 바뀌는지로 진행을 볼 수 있습니다.

## 열기가 안 됩니다

파일이 휴지통에 있거나 이름이 바뀌었을 수 있습니다. **폴더에서 보기**로 탐색기가 어디를 여는지 확인하세요. 목록은 예전에 읽은 경로를 기억합니다.

## 처음부터 다시 읽기를 누르면 원본이 지워지나요

아닙니다. 이 앱의 검색 목록(`index.db`)만 지우고 폴더를 다시 읽습니다.

## Mac에서 쓸 수 있나요

Mac **설치 파일은 없습니다.** 개발할 때만 .NET SDK로 `dotnet run` 하면 창이 뜹니다. → [개발](개발.md)
