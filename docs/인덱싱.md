# 인덱싱

인덱싱은 원본 폴더를 읽어서 **이 앱만 쓰는 검색 목록**을 만드는 일입니다. 목록은 설치 폴더가 아니라 사용자 데이터에 둡니다. 업데이트를 해도 목록은 남습니다.

- Windows: `%LOCALAPPDATA%\DocuLensLocal\userdata\index.db`
- 개발용 macOS: `~/Library/Application Support/DocuLensLocal/userdata/index.db`

## 어디까지 읽나

고른 폴더와 **그 아래 하위 폴더**만 재귀해서 읽습니다. 한 단계 **위** 폴더의 파일은 읽지 않습니다.

예: 화면 아래 경로가 `...\인수인계\계약서_스캔`이면, 바로 위 `인수인계`에 둔 엑셀·한글은 목록에 안 들어갑니다. 그 파일까지 찾으려면 **폴더 변경**으로 `인수인계`를 고른 뒤 인덱싱하세요.

## 지원 파일

읽는 것: `.pdf`, `.docx`, `.doc`, `.hwp`, `.hwpx`, `.xlsx`, `.xlsm`, `.xls`

건너뛰는 것: `.txt`, PNG 등 이미지, 이름 앞이 `~` 또는 `.`인 파일(Word/Excel `~$` 잠금 포함), `.xlsb`

글자가 들어 있는 파일은 그 글자를 읽습니다. 스캔(그림만 있는 페이지)은 설치본에 들어 있는 Tesseract로 OCR합니다. 사용자는 페이지가 하나씩 뜨는 화면을 보지 않습니다. Windows 설치본에는 한국어·영어 언어팩이 들어 있어 Tesseract를 따로 설치하지 않아도 됩니다.

원본은 **읽기만** 합니다. 크기·수정 시각을 바꾸지 않습니다. Word·엑셀·한글이 파일을 연 상태에서도 공유해서 읽으려고 합니다.

## 버튼

| 동작 | 설명 |
|---|---|
| 인덱싱 (처음) | 고른 폴더를 읽어 목록을 만듭니다. |
| 새 파일 인덱싱 | 신규·변경만 읽습니다. 이미 본문이 있는 같은 파일은 건너뜁니다. 다만 엑셀·한글·Word 본문이 비어 있으면 다시 읽습니다. 빈 PDF는 반복 OCR하지 않습니다. |
| 처음부터 다시 인덱싱 | 검색 목록만 지우고 폴더를 전부 다시 읽습니다. |
| 자동 감시 | 앱이 켜져 있고 인덱싱이 끝난 폴더에 파일을 넣거나 바꾸거나 지우면, 잠깐 기다린 뒤 새 파일만 읽습니다. `~$`·임시 저장도 감시를 깨웁니다. |

폴더만 고른 최초 실행 화면에서는 감시하지 않습니다.

## 진행 표시

검색 화면 오른쪽 위 알약은 대략 이런 형식입니다.

`인덱싱 완료 · 278건 · 본문 278건 · OCR 707쪽`

- 건수: 목록에 들어간 파일 수
- 본문: 글자가 하나라도 읽힌 파일 수
- OCR: 스캔으로 읽은 쪽 수

읽는 중에는 `본문 읽는 중`, `새 파일 읽는 중`, `이어서 읽는 중`으로 바뀝니다. 업데이트 중에 인덱싱이 끊겨도, 다시 켠 뒤 **남은 파일부터** 이어 갈 수 있습니다.
